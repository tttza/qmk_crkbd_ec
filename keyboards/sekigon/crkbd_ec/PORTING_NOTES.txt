Porting notes (rp2040 branch -> latest QMK pico)

What stays from the working rp2040 branch:
- Platform: legacy Pico stack (`PLATFORM_KEY = pico`, `MCU_FAMILY/MCU_SERIES = PICO/RP2040`), rp2040 bootloader, and bs2_default boot2 to avoid BOOTSEL drops.
- Storage: wear-leveling with the rp2040_flash backend and dynamic keymap capped at 2047 bytes so it fits the RP2040 flash window.
- Split/serial: soft-serial on GP1, PIO index forced to 1, and speed preset 2 (~115200 baud) for Xiao RP2040 stability. Defaults are EE_HANDS + SPLIT_USB_DETECT; override with `MASTER=left/right` when needed.
- Safety: double-reset BOOTSEL path and watchdog disabled for debugging on Xiao RP2040.
- Lighting: RGB Matrix re-enabled using the custom ws2812 driver; VIA lighting save path is guarded and shared between RGB Matrix/RGB Light.

Other cleanups:
- Removed unused handedness shim sources and legacy info.json backups.
- Console print implementation is linked explicitly (`tmk_core/common/pico/print.c`).
